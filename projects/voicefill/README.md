# VoiceFill

A browser extension exploring voice-driven form input and speech-aware interaction.

## What it demonstrates

- Browser extension architecture
- Voice activity detection for spoken input
- WebAssembly integration in a web application
- Background/content script communication
- Options and configuration UI
- Client-side JavaScript event processing
- Voice-driven interaction patterns

## Technology

- JavaScript
- WebRTC VAD
- WebAssembly
- Browser Extension APIs
- HTML / CSS

## Architecture

The extension combines background and content scripts with browser UI components. Voice processing is supported through a WebRTC voice activity detection module and WebAssembly-based processing.

## Status

Legacy portfolio project. The implementation is retained because it demonstrates browser engineering, low-level voice processing integration, and experimentation beyond conventional CRUD applications.

## Repository note

Generated packaged artifacts have been removed from the portfolio copy. The source implementation and relevant runtime assets are retained so the engineering approach remains reviewable.
