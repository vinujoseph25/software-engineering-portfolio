When to use flux:
1. When a data that needs to be used at multiple components in the app, passing it as props makes components break the single responsibility principle.
2. And also there might be chances of mutating data anywhere
Stores solve the problem.

When Redux is used:
1. State is stored locally within a component. When that state needs to be shared across components, it is passed down as props.
2. And if in the sub components, if that needs to be mutated, and then passing callback to handle the change in sub components.
And it would be difficult as the no. of component increases.
And here we go with Redux.
When using Redux, state is stored globally in redux stores.
Any component that needs access to that value, may subscribe to the store and get value.
Basically this is done using container components (Stateful).

This centralizes all data and makes it easier for components to get data it needs.

redux-saga:
1.	redux-saga is a library that aims to make application side effects (i.e. asynchronous things like data fetching and impure things like accessing the browser cache) easier to manage,
more efficient to execute, easy to test, and better at handling failures.

2.	It uses an ES6 feature called Generators to make those asynchronous flows easy to read, write and test. By doing so, these asynchronous flows look like your standard
synchronous JavaScript code. (kind of like async/await, but generators have a few more awesome features we need) 
(taken from docs)Contrary to redux thunk, we don't end up in callback hell, we can test asynchronous flows easily and actions stay pure.

Refer here: redux-saga

redux-thunk:
1.	Redux Thunk middleware allows you to write action creators that return a function instead of an action. The thunk can be used to delay the dispatch of an action, 
or to dispatch only if a certain condition is met. 

An action creator that returns a function to perform asynchronous dispatch:
export function IncrementWithDelay() {
    return (dispatch) => {
        fetch(`https://reqres.in/api/users?delay=3`, {
            method: "POST",
            headers: {
                'Accept': 'application/json',
                'Content-Type': 'application/json',
            }
        }).then(
            (response) => {
                return response.json();
            }
            ).then(
            (response) => {
                console.log("response received", response);
                dispatch(Increment());
            }
            )
    }
}
