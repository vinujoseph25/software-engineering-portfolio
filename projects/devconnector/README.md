# DevConnector

A full-stack social platform for developers, built around a REST API and React client.

## What it demonstrates

- User registration and authentication
- JWT-based protected API routes
- Developer profiles and profile information
- Posts and social interactions
- MongoDB data modelling with Mongoose
- Input validation and password hashing
- React client integration with a Node.js/Express backend

## Technology

- React
- Node.js
- Express
- MongoDB / Mongoose
- JSON Web Tokens (JWT)
- bcrypt
- REST APIs

## Architecture

The application is split into a React frontend and an Express/Node.js backend. The backend exposes API routes for authentication, profiles and posts, while MongoDB provides persistent application data.

## Status

Legacy portfolio project. The code is retained as an example of full-stack JavaScript development and API-driven application architecture.

## Security

Local credentials are intentionally excluded from the repository. Configure environment-specific values locally rather than committing secrets.
