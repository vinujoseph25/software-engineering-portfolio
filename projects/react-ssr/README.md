# React SSR

A server-side rendering project exploring how React applications can be rendered on the server and delivered to the browser as HTML before client-side execution takes over.

## What it demonstrates

- React server-side rendering concepts
- Node.js and Express application delivery
- Webpack-based build tooling
- Separation of server and client concerns
- Rendering React components outside the browser
- Full-stack JavaScript application structure

## Technology

- React
- Node.js
- Express
- Webpack
- JavaScript

## Architecture

The server is responsible for preparing the initial React-rendered response, while the browser loads the client-side bundle for subsequent interaction.

## Status

Legacy portfolio project. The implementation is retained as an example of frontend architecture, build tooling, and server/client rendering patterns.
